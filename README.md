# KIPOT / PORTFOLIO

> **MULTIPLE PERSPECTIVES, ONE PRACTICE.**

A personal portfolio built around an interdisciplinary way of working — connecting **law, digital work, markets, literature, and culture** in one visual system.

---

## The idea

This is intentionally not a résumé-shaped website.

It is a **working map** of things built, questions studied, systems explored, and ideas that keep returning. The interface uses an editorial art direction: oversized typography, paper/ink contrast, motion, grain, asymmetric composition, and a single portrait as the visual anchor.

### Five lenses

| 01 | LAW | Research · Argument · Institutions |
| --- | --- | --- |
| 02 | DIGITAL | Web · Interface · Visual systems |
| 03 | MARKETS | Risk · Probability · Decision making |
| 04 | LITERATURE | Essays · Philosophy · Language |
| 05 | CULTURE | Objects · Habits · Context |

---

## What is inside

**Cinematic hero** — oversized statement, portrait treatment, orbiting rings, pointer interaction, and scroll cue.

**Editorial sections** — statement, five-lens practice grid, selected work archive, notes, and a high-contrast contact close.

**Micro-interactions** — scroll progress, reveal transitions, portrait tilt, mobile navigation, marquee movement, and reduced-motion support.

**Static by design** — no framework, no build pipeline, no dependency maze.

## Run locally

Serve the repository with any static HTTP server:

~~~bash
python -m http.server 5500
~~~

Open **http://localhost:5500**

You can also drop the repository into VS Code and use Live Server.

---

## Publish

The project works with static hosting out of the box, including **GitHub Pages** and **Vercel**.

For GitHub Pages:

**Settings → Pages → Deploy from a branch → main → /(root)**

---

## Personalize

Replace **assets/kipot.jpg** to change the hero portrait.

Main content lives in **index.html**.

Visual direction lives in **styles.css**.

Interaction logic lives in **script.js**.
